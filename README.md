# GitHub Student ID & Group Inserter

大学等の演習講義において、学生のGitHubアカウントと学籍番号・氏名・グループ（班）を紐付け、GitHub画面上に直接バッジとして表示するChrome拡張機能です。

PR、コミット履歴、Issue、Discussionsなどで「誰の提出物・作業か」を一目で識別できるようにします。

![](https://nagatani.github.io/github-student-id-extension/docs/images/sc-githup-badge-02.png)


---

## 主な機能

- **GitHub画面上へのバッジ自動挿入**: アカウント名の直後に `[グループ]` `[学籍番号 氏名]` をインライン表示
- **柔軟な名簿インポート**: Excelやスプレッドシートのセル（TSV / CSV）をコピー＆ペーストするだけで即時反映
- **大文字・小文字の自動補正**: GitHubのID表記ゆれを吸収してマッチング
- **完全ローカル動作**: 入力した学生データはブラウザ内（`chrome.storage.local`）にのみ保存され、外部通信は一切行いません

---

## インストール手順（開発版）

1. このリポジトリをクローンまたはZIPダウンロードして展開します。
2. Google Chrome（またはEdge）を開き、アドレスバーに `chrome://extensions` と入力します。
3. 右上の **「デベロッパーモード」** をオンにします。
4. 左上の **「パッケージ化されていない拡張機能を読み込む」** をクリックし、展開したディレクトリの中から「`src`」ディレクトリを選択します。

---

## 使い方・名簿の登録

![](https://nagatani.github.io/github-student-id-extension/docs/images/sc-option-page-02.png)

1. 拡張機能アイコンを右クリックし、**「オプション」** を開きます（または拡張機能一覧の「詳細」→「拡張機能のオプション」）。
2. 名簿入力欄に、以下のいずれかの形式でデータを貼り付けて **「保存する」** をクリックします。

### 貼り付けフォーマット例

#### 1. Excel / スプレッドシートからのコピペ（推奨）
Excelのセルをコピーしてそのまま貼り付けられます（タブ区切り / カンマ区切りに対応）。

```text
GitHubID	学籍番号	氏名	グループ
octocat	K24001	山田 太郎	チームA
student-handle	K24002	佐藤 花子	チームB

```

※1行目にヘッダー（`GitHubID` など）が含まれていても自動で除外されます。

#### 2. JSON形式

```json
{
  "octocat": { "id": "K24001", "name": "山田 太郎", "group": "チームA" },
  "student-handle": { "id": "K24002", "name": "佐藤 花子", "group": "チームB" }
}

```

3. GitHubを開くと、該当する受講生のアカウント名の後ろに色分けされたバッジが表示されます。

## デバッグ・ログ確認

ブラウザの開発者ツール（F12）の「Console」タブを開くと、割り当て状況が確認できます。

* `✅ 割り当て成功: @username -> K24001 山田太郎 (チームA)`
* `⚠️ 未登録ユーザー: @unknown-user (名簿データに見つかりません)`

名簿への登録漏れやIDの間違いを特定する際にご活用ください。
